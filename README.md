# Instapro

MVP социальной сети для обмена фотографиями

## Реализованная функциональность

### ✅ Основные функции
- **Авторизация и регистрация пользователей**
  - Регистрация с валидацией данных (логин, пароль, имя, фото)
  - Авторизация с проверкой учетных данных
  - Сохранение сессии в localStorage
  - Автоматическая проверка авторизации при загрузке
  - Кнопка "Выйти" для завершения сессии

- **Общая лента постов**
  - Отображение всех постов от всех пользователей
  - Доступ для авторизованных и неавторизованных пользователей
  - Красивое форматирование дат ("только что", "5 минут назад", etc.)
  - Переходы к профилям пользователей по клику на имя

- **Лента постов конкретного пользователя**
  - Отображение постов только выбранного пользователя
  - Доступ для всех пользователей
  - Полная функциональность лайков и удаления

- **Добавление новых постов**
  - Загрузка изображений в облако
  - Валидация обязательных полей (текст и фото)
  - Доступ только для авторизованных пользователей
  - Мгновенное обновление ленты после добавления

- **Система лайков**
  - Постановка и снятие лайков
  - Счетчик количества лайков
  - Работает на всех страницах (общая лента и профили пользователей)
  - Доступ только для авторизованных пользователей

- **Удаление постов**
  - Удаление собственных постов
  - Подтверждение действия
  - Мгновенное обновление интерфейса

### ✅ Техническая реализация
- **API интеграция**
  - Получение постов всех пользователей
  - Получение постов конкретного пользователя
  - Добавление новых постов
  - Лайки и дизлайки
  - Удаление постов
  - Загрузка изображений в облако

- **Безопасность**
  - Защита от XSS атак (экранирование HTML)
  - Валидация данных на клиенте и сервере
  - Безопасная обработка пользовательского ввода
  - Правильная обработка ошибок API

- **Пользовательский интерфейс**
  - Адаптивный дизайн для всех устройств
  - Плавные анимации и переходы
  - Hover-эффекты и визуальная обратная связь
  - Современный и интуитивный интерфейс

- **Доступность (Accessibility)**
  - ARIA-атрибуты для скрин-ридеров
  - Поддержка навигации с клавиатуры
  - Семантическая HTML-разметка
  - Alt-атрибуты для всех изображений

- **Vanilla JavaScript** - без фреймворков
- **CSS3** - современные стили и анимации

- **Fetch API** - для работы с сервером
- **LocalStorage** - для сохранения сессии

## Запуск проекта

1. Клонируйте репозиторий
2. Запустите локальный сервер:
   ```bash
   python -m http.server 8000
   ```
3. Откройте `http://localhost:8000` в браузере

## API

Проект использует API Instapro:
- **Base URL**: `https://wedev-api.sky.pro/api/v1/prod/instapro`
- **Авторизация**: Bearer токен
- **Endpoints**: посты, лайки, загрузка изображений
