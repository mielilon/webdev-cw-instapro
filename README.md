# Instapro

MVP социальной сети для обмена фотографиями

## Первоначальная оценка

30 часов

## Фактически затраченное время

32 часов


## Изменения в версиях

1.0.2 --> реализована интеграция верстки списка постов в API, так же реализована страница добавления поста
1.0.3 --> реализована страница каждого пользователя с постами
1.0.4 --> реализовано добавление/удаление лайков под каждым постом

1.1.1 --> улучшена безопасность
1.1.2 --> добавлена возможность перехода на главную страницу из страницы пользователя
1.1.3 --> реализовано удаление поста (временно не работает из-за сервера)
