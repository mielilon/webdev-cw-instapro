# Instapro — курсовая работа

## Что реализовано

- Интеграция ленты постов с API
- Страница добавления поста (загрузка фото + описание + валидация)
- Страница постов конкретного пользователя
- Лайки (постановка/снятие, счётчик, без перезагрузки)
- Форматирование даты на русском через date-fns

## Оценка времени

Оценка: 5 часов. Факт: 10 часов.

## Дополнительные фичи
